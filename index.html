        免税州说明

        美国的销售税由各州自行规定，下列 5 个州不征收州级销售税。Apple ID 的账单地址填这些州时，App Store 购买和礼品卡充值都不会额外加税，标价多少就付多少。

        注册美区 Apple ID 步骤
        1. 在 iPhone 的「设置 → 媒体与购买项目」中退出当前账户，或在电脑上打开 account.apple.com 创建新账户。
        2. 国家或地区选择 United States（美国）。
        3. 付款方式选择 None（无）。如果没有这个选项，先在 App Store 里点「获取」一个免费 App，再从弹出的窗口中创建账户。
        4. 账单地址照本页的结果填：Street、City、State、ZIP 分别对应街道、城市、州、邮编。「State」在下拉框里选州名，本页也显示了缩写。
        5. 账单地址里的电话可以填本页生成的号码（Area Code 是区号，Phone 是 7 位号码）。
        6. 账户安全验证用的「受信任手机号」必须能收短信，填你自己的真实号码，国内 +86 号码可以用。
        7. 姓名可以填生成的英文名，也可以填自己的拼音。
